# Ezreal Archive Backend

A Cloudflare Worker that serves as the API backend for the Ezreal Media Archive.
Here is the repository for the frontend: [Ezreal Media Archive](https://github.com/timfernix/ezreal-archive)

## What this project is

The Ezreal Archive Backend is a Cloudflare Worker that queries a D1 database and exposes a REST API consumed by the frontend to browse official Ezreal assets.
